Poniżej masz **minimalny, operacyjny słownik** — trzy klasy z jasno wskazanymi osiami różnic. Traktuj to jak typy w systemie, nie „opisy treningowe”.

------

# 🔴 Heavy Compound

**Definicja (esencja):**
Wielostawowe ćwiczenie o **wysokim obciążeniu absolutnym**, angażujące duże masy mięśniowe, generujące **wysoki koszt systemowy (CNS + global fatigue)** i wysoki bodziec mechaniczny.

**Profil (wektor):**

```math
\text{systemic fatigue} \uparrow\uparrow,\ \text{local stimulus} \uparrow\uparrow
```

**Odróżnia je od innych:**

- **najwyższy koszt regeneracyjny na serię**
- **największy wpływ na HRV/RHR**
- **najmniejsza tolerancja objętości**

**Przykłady:** bench press, OHP, ciężkie podciąganie, suwnica/leg press.

------

# 🟡 Secondary Compound

**Definicja (esencja):**
Wielostawowe ćwiczenie o **umiarkowanym obciążeniu i stabilizacji**, dalej dające silny bodziec lokalny, ale przy **niższym koszcie systemowym** niż Heavy Compound.

**Profil (wektor):**

```math
(\text{systemic fatigue} \uparrow,\ \text{local stimulus} \uparrow\uparrow)
```



**Odróżnia je od innych:**

- **dobry stosunek bodźca do kosztu**
- **wyższa tolerancja objętości niż HC**
- często bardziej „prowadzone”/stabilne (maszyny, podparcie)

**Przykłady:** incline machine press, chest-supported row, seated row, Arnold press.

------

# 🟢 Isolation

**Definicja (esencja):**
Ćwiczenie jedno- lub quasi-jednostawowe, ukierunkowane na **lokalny bodziec mięśniowy przy minimalnym koszcie systemowym**.

**Profil (wektor):**

```math
(\text{systemic fatigue} \downarrow,\ \text{local stimulus} \uparrow)

```

**Odróżnia je od innych:**

- **niski wpływ na układ nerwowy**
- **wysoka tolerancja objętości**
- **łatwe do dodawania/odejmowania (buffer objętości)**

**Przykłady:** fly, lateral raise, face pull, curls, triceps extensions, łydki.

------

# 📊 Osie różnic (jawnie)

| Oś                          | Heavy Compound | Secondary Compound    | Isolation         |
| --------------------------- | -------------- | --------------------- | ----------------- |
| **Systemic fatigue (CNS)**  | 🔴 wysokie      | 🟡 średnie             | 🟢 niskie          |
| **Local stimulus**          | 🔴 wysokie      | 🔴 wysokie             | 🟡 średnie         |
| **Stability / prowadzenie** | niska–średnia  | średnia–wysoka        | wysoka            |
| **Load absolutny**          | wysoki         | średni                | niski             |
| **Tolerancja objętości**    | niska          | średnia               | wysoka            |
| **Rola w planie**           | fundament      | efektywny „workhorse” | bufor/fine-tuning |

------

# TL;DR (jednozdaniowo)

- **Heavy Compound** = maks bodźca **i** maks kosztu.
- **Secondary Compound** = wysoki bodziec przy **lepszym stosunku bodziec/koszt**.
- **Isolation** = **niski koszt**, kontrolowany bodziec → narzędzie do regulacji objętości.
