# Anatomia

## Trunk

![](Pasted%20image%2020260829144043.png)

#### Main Regions
- **Thorax (Chest):** The upper part of the trunk that houses the heart and lungs, protected by the rib cage.
- **Abdomen:** The middle section located below the diaphragm that contains primary digestive and excretory organs.
- **Pelvis:** The lower basin-like region that holds the urinary bladder, reproductive organs, and rectum.
- **Back:** The posterior region containing the spine and supporting muscles.
#### Major Cavities
- **Thoracic Cavity:** Encloses the lungs (in pleural sacs) and the heart.
- **Abdominal Cavity:** Houses the stomach, liver, intestines, and kidneys.
- **Pelvic Cavity:** Contains the terminal gastrointestinal tract and pelvic viscera. 
#### Skeletal Framework
- **Vertebral Column (Spine):** Runs down the midline of the back as the main structural axis. It includes 12 thoracic vertebrae, 5 lumbar vertebrae, and the sacrum/coccyx.
- **Rib Cage and Sternum:** Protects core thoracic organs and assists in respiration mechanics.

# Muscles of ABS
![](Pasted%20image%2020260829152717.png)

| Muscle                 | Główna rola treningowa                                                             |
| ---------------------- | ---------------------------------------------------------------------------------- |
| `rectus_abdominis`     | trunk flexion + anti-extension                                                     |
| `obliques`             | rotation, anti-rotation, lateral flexion + trunk flexion                           |
| `transverse_abdominis` | przede wszystkim bracing / anti-extension / anti-rotation                          |
| `iliopsoas`            | hip flexion — często współpracuje w leg raises, ale nie traktowałbym go jako „abs” |
| `erector_spinae`       | antagonistyczna/stabilizacyjna część trunk complex                                 |
