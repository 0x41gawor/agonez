## What exists now

All paths are under `be/`. No application code changed.

**`scripts/test_db.sh [start|stop]`** — starts or reuses `postgres:15` (container `agonez-it-db`) on
`127.0.0.1:<random port>`, random password, data on tmpfs, `fsync=off`, label
`agonez.integration-test=true`. Prints two `export` lines (`AGONEZ_TEST_DATABASE_URL`,
`AGONEZ_TEST_DB_CONTAINER`). `AGONEZ_TEST_DB_CONTAINER` picks another name (prefix `agonez-it-`).
It only reuses or removes containers carrying its label.

**`tests/integration/conftest.py`**

- Every test in the directory gets the `integration` marker; marked tests are skipped without
  `AGONEZ_TEST_DATABASE_URL`.
- Before any connection the URL is verified: loopback host, container named in
  `AGONEZ_TEST_DB_CONTAINER` (never `agonez-db`), carrying the label, publishing that port. A set URL
  that fails this check fails the tests; it does not skip them.
- Template `agonez_it_template`, built once per session: owner roles from the dump's `OWNER TO`
  statements, newest `agonez_db_backup_*.sql` by file name (override `AGONEZ_TEST_DB_DUMP`) replayed
  by `psql` in the container, then `run_migrations()`. Dropped at session end.
- Fixtures:

| Fixture | Value |
| --- | --- |
| `database_name` | per-test clone of the template, dropped afterwards |
| `settings`, `pool`, `db` | `Settings` for the clone; the opened app pool; an autocommit dict-row connection |
| `app`, `client` | `create_app(settings, pool)`; `httpx.AsyncClient` over ASGI |
| `clock` | `FrozenClock`, today = `FROZEN_TODAY` (Monday 2027-01-04); assign `clock.today` |
| `plan_repository`, `plan_service`, `execution_repository`, `execution_service`, `mobile_execution_repository`, `mobile_execution_service` | the app's instances; `execution_service` uses `clock` |
| `database_server`, `template_database` | session scope; `database_server.connect_admin()`, `.settings(db, dir)` for extra databases |

**`tests/integration/builders.py`**

- `PlanSpec`, `DaySpec`, `SlotSpec`, `SetSpec`, `training()`, `rest()`; `exercise_slugs(db, n)`.
- `make_library_plan(client, spec)` → saved draft artifact; `day_payload(ordinal, DaySpec)` for adding
  a day to an existing draft.
- `make_run(client, revision_id, starts_on, count, name=…)` → overview; `run_sessions(overview)` →
  sessions in calendar order.
- `finalize_session(client, session_id, performed_on, load_kg=20.0, device_id=…)` →
  `FinalizedWorkout(workout_id, prescription, result)`: fallback prepare, start, ops (every set
  performed), finalize.
- `expect(response, status=200)`; `table_names(db, "plans", "exec")`;
  `snapshot_tables(db, tables, where=None)` (async) → `{table: "<rows>:<sha256>"}`. Filter with
  `where={"exec.microcycles": ("row_.plan_run_id = %s", (run_id,))}`.

## Deviations from the design

Small additions to `06` T0.1; no contract or architecture change, docs `00`–`07` not edited:

- `snapshot_tables` is a coroutine (the harness connection is async), takes an optional `where` (for
  run-filtered snapshots, T-INT-RUN-06) and prefixes each hash with the row count.
- The harness refuses databases not started by `test_db.sh` (label and port check). A host with its own
  `psql` or a CI service database is therefore not supported.

## For the next tasks

- Import helpers with `from builders import …` and `from conftest import FrozenClock` (no packages;
  pytest puts the test directory on `sys.path`).
- **The clock only drives `ExecutionService`.** Mobile `context` and `plan-runs` read the real date
  unless the request passes `?date=`; both also run date-based status transitions.
- The template holds the production-like data, including real runs. Their dates are relative to real
  2026, so at the frozen date a read reconciles their pending sessions to `missed`. Filter assertions
  by run or plan id.
- `finalize_session` sends no `off_schedule` acknowledgement: `performed_on` must be the scheduled date
  of a session that is still `scheduled` and next in its track. Missed or early sessions need their own
  start payload.
- `client` raises unhandled server errors inside the test. To assert an HTTP 500 (T-FAIL-02), or a
  status for a request that currently 500s (T-REG-02), build a client with
  `httpx.ASGITransport(app=app, raise_app_exceptions=False)`.
- Migration tests (T2.1/T2.3) need a database *before* new migrations: the template already has all of
  them applied. Add a fixture beside `template_database` that reuses `_restore` and applies migrations
  selectively.
- One pytest session per container (fixed template name; no xdist). Parallel worktrees: export a
  distinct `AGONEZ_TEST_DB_CONTAINER` before running the script.
- Once `AGONEZ_TEST_DATABASE_URL` is exported, a plain `pytest` also runs the integration tests, and
  errors if the container has been stopped; `unset` it or use a new shell.
