## What exists now

No migrations, no new routes, no new `UPDATE`/`DELETE` on `plans.*` (promotion only inserts, so the
T-IMM-03 allow-list is unchanged). Execution and mobile code are untouched.

`POST /api/plans/{plan_id}/duplicate` takes an optional body (`04` §4):

| Name (`be/src/agonez_api/modules/plans/`) | What it does |
| --- | --- |
| `schemas.PlanDuplicateRequest` | `name: str \| None` (1–200, not blank, used as given), `source_revision_id: int \| None` (≥ 1). Unknown fields → 422. |
| `router.duplicate_plan` | Body is optional: no body, an empty JSON body, `null`, `{}` and null fields all mean the defaults. |
| `PlanService.duplicate_plan(plan_id, payload=None)` | Passes the two fields to the repository. |
| `PlanRepository.duplicate_plan(plan_id, *, name=None, source_revision_id=None)` | One transaction, source plan `FOR SHARE`. Source = the DRAFT, or the given revision of this plan. New `library` plan: given name or `_duplicate_plan_name` (library names only); description, accent and cover of the source **plan** (not revision-scoped, D14); `source_plan_id = plan_id` only when the source plan is a run plan; revision 1 `DRAFT`, `based_on_revision_id = source`; `copy_revision(…, regenerate_progression_ids=True)`. |
| `PlanRepository._find_plan_revision` | `PlanDomainValidationError` → 422 `{"detail": "source_revision_id 99 does not belong to plan 41"}`, the same for an unknown id and another plan's revision. |

Errors: unknown plan → 404 `{"detail": "Plan 41 was not found"}` (also when a
`source_revision_id` is sent); body validation → FastAPI's default 422.
